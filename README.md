# studying-app

A local-first native desktop application for studying: handwritten and typed notes on an
infinite canvas, PDF annotation, notebooks, and course/project/task planning.

**Stack:** C++20 · Qt 6 (Widgets) · OpenGL 3.3 (behind a renderer abstraction) · SQLite ·
CMake · GoogleTest · GitHub Actions.
